Section 2

解析対象：Landau-Zener モデル（2準位系）

2つのエネルギー準位が時間変化するハミルトニアン下で「交叉点付近を通過する」現象。 有機分子・半導体の光励起、CNT官能基化計算のS₀→S₁遷移と同じ物理クラスに属する。

エネルギー準位の時間変化（avoided crossing）— α が大きいほど掃引が速く、非断熱遷移が起きる

断熱定理（CAE類推）: 外力の変化が十分ゆっくりならば系は準静的に応答する（静的解析が動的解析を近似できる条件）。 量子系でも同様に、ハミルトニアンの変化が遅ければ状態は基底状態に追従し続ける（断熱遷移）。 変化が速い場合は「基底状態に追従できない」非断熱遷移が生じる。

本検討のハミルトニアン（掃引速度 α, ギャップ Δ=1）：

# H(t) = α·t·Z + Δ·X （t ∈ [-T/2, +T/2]）
# 断熱条件: α / (2Δ)² ≪ 1

α = 0.5 → α/(2Δ)² = 0.125 # 断熱（基底状態追従）
α = 5.0 → α/(2Δ)² = 1.25 # 非断熱（diabatic 状態に留まる）
Section 3

3段階検証パイプライン

実機投入前に2段階の事前検証を行う設計は、CAEにおける 「粗メッシュ確認 → 細メッシュ本計算 → 実験比較」に相当する。

高精度シミュレーション

Catalyst + lightning.qubit

JIT コンパイル（@qjit）＋ jax.vmap で全掃引速度を並列計算。ノイズなし・N_STEPS=100 の理論値。

ノイズ入りシミュレーション

AerSimulator（実機模擬）

ゲート誤り率 0.1%・読み出し誤り率 1% のノイズモデルを付与。N_STEPS=15 の浅い回路。

実機実行

ibm_kingston（QPU）

IBM Quantum Platform 経由で実機投入。shots=8192 で統計誤差 ±0.55%（1σ）を確保。

Section 4

回路設計：時間発展演算子のゲート分解

時間ステップ毎の演算子 exp(−iH(t)Δt) を IBM ネイティブゲート（RY, RZ）に厳密分解する。 これはFEMの陽的時間積分で各ステップの剛性行列をローカル演算として組み立てる工程に相当する。

# 各時間ステップ t_i での演算子分解：
# exp(-i·(a·Z + Δ·X)·dt) = RY(-φ) → RZ(2‖H‖dt) → RY(+φ)

# ‖H‖ = √(a² + Δ²), φ = arctan2(Δ, a)

RY(-phi, wires=0) # 回転軸を Z から H 方向へ
RZ(2*norm*dt, wires=0) # 固有値に沿った回転（物理的時間発展）
RY(+phi, wires=0) # 回転軸を元に戻す
回路仕様 値 備考
量子ビット数1 qubitIBM実機の1本で足りる
